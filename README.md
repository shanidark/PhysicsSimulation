# Симуляция физики твёрдых тел

Курсовая работа, 2й курс.

Симулятор трёхмерной физики твёрдых тел с визуализацией и интерактивным UI на базе ImGui.

## Возможности

**Физика**
- Твёрдые тела: боксы и сферы
- Детектирование столкновений методом SAT (Separating Axis Theorem)
- Sequential impulse solver с накоплением импульсов
- Warm starting — перенос накопленных импульсов между кадрами для стабильности
- Трение (геометрическое среднее коэффициентов тел), упругость (restitution)
- Система засыпания (sleeping): тела с нулевой активностью исключаются из расчётов
- Rolling resistance для сфер
- Позиционная коррекция с раздельным весом по количеству контактных точек

**Рендеринг**
- OpenGL 2.1 fixed-function pipeline
- Скайбокс (цветной куб, следует за поворотом камеры)
- Атмосферный туман, сглаживающий горизонт
- Цвет тел по состоянию: активный / спящий / статичный
- Отображение нормалей контактов (опционально)
- HUD с подсказками (FreeType)

**ImGui панель (Tab)**
- Спавн боксов и сфер с настройкой позиции, размера, массы
- Удаление последнего тела
- Рестарт сцены
- Настройка гравитации, трения пола, порога скорости для restitution
- Параметры солвера и системы засыпания
- Статистика сцены в реальном времени

## Сборка

```sh
cmake -S . -B build
cmake --build build
```

Зависимости: OpenGL, GLFW, Freetype. ImGui подтягивается автоматически через CMake FetchContent.

## Запуск

```sh
./build/physics_simulation
```

## Управление

| Клавиша | Действие |
|---------|----------|
| `Tab` | Открыть/закрыть панель Physics |
| `Space` | Пауза / продолжить |
| `N` | Один тик (во время паузы) |
| `C` | Показать нормали контактов |
| `W/S` | Камера вверх/вниз |
| `A/D` | Камера влево/вправо |
| `Q/E` | Приблизить/отдалить |
| `Esc` | Выход |

## Параметры физики (ImGui)

| Параметр | Описание |
|----------|----------|
| **Gravity** | Вектор гравитации |
| **Ground friction** | Коэффициент трения пола |
| **Rest velocity** | Порог скорости сближения — ниже него restitution не применяется (нет отскока при мягком касании) |
| **Solver iters** | Число итераций солвера за шаг — больше итераций стабильнее стопки, дороже CPU |
| **Velocity thr** | Порог скорости для начала отсчёта таймера засыпания |
| **Delay** | Время (с) непрерывного покоя до засыпания тела |

## Архитектура

```
src/
  math/           — Vec3, Mat3, Quat, базовые операции
  physics/
    rigid_body     — состояние тела, интегратор, моменты инерции
    contact        — структура контакта (точка, нормаль, накопленные импульсы)
    contact_solver — warm starting, sequential impulse, позиционная коррекция
    physics_world  — генерация контактов (SAT box-box, sphere-box, sphere-sphere, ground)
  render/
    debug_renderer — OpenGL 2.1, скайбокс, ImGui
    font_renderer  — растеризация текста через FreeType
  main.cpp         — игровой цикл с фиксированным шагом (120 Hz)
```
