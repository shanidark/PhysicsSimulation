# Симуляция физики

Курсовая работа за 2й курс

В текущем состоянии в одной точке спавнятся кубики и сферы, все отталкиваются друг от друга, сферы катаются и даже трутся об поверхность, из-за чего замедляются по мере своего движения вплоть до остановки.
Текст сделан с помощью FreeType

## Сборка

```sh
cmake -S . -B build
cmake --build build
```

## Запуск

```sh
./build/physics_simulation
```

## Управление
(буквы русские)

- `Пробел`: Пауза
- `Т`: Следующий тик (во время паузы)
- `С`: Включить отображение нормалей контактов
- `Ц/Ф/Ы/В`: Управление поворотом камеры
- `Й/У`: Приближение камеры
- `Побег`: Закрыть окно
